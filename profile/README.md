# GRANDstack

**GraphQL and Neo4j, for developers and agents.** A Neo4j graph, a GraphQL API generated from one schema file, a typed React app, and an MCP server so agents can use the same API. Small repositories you can clone and run in Docker. Website and docs: **https://grandstack.ai**.

| Repository | What it is |
| --- | --- |
| [grandstack](https://github.com/grand-stack/grandstack) | The umbrella: compose files for every setup, overview, architecture, tutorial, agent guide |
| [grandstack-server](https://github.com/grand-stack/grandstack-server) | The GraphQL server: Neo4j and a schema file in, a GraphQL API out |
| [grandstack-web](https://github.com/grand-stack/grandstack-web) | The React app: faceted search, compare, graph views, people, create, edit, delete |
| [grandstack-auth](https://github.com/grand-stack/grandstack-auth) | Opt-in auth: gateway, row-level rules, Keycloak dev realm, demo client |
| [grandstack-agents](https://github.com/grand-stack/grandstack-agents) | How agents work with GraphQL: an MCP server, a direct agent loop, guardrails |
| [grandstack-federation](https://github.com/grand-stack/grandstack-federation) | Federation: the server as a subgraph, a Wikipedia subgraph, a gateway |
| [grand-stack.github.io](https://github.com/grand-stack/grand-stack.github.io) | The website, grandstack.ai |

Start with the [quickstart](https://grandstack.ai/quickstart/). Working with a coding agent? Point it at [grandstack.ai/llms.txt](https://grandstack.ai/llms.txt).
